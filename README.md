# Popburst

A poppy, colorful [Omarchy](https://omarchy.org/) theme for deep work: dark ink surfaces, candy-bright syntax accents, and abstract wallpapers that mix mountain trails with late-night coding energy. Built for long sessions — focused, a little fun, still easy on the eyes.

## Install (anywhere)

```bash
omarchy theme install https://github.com/bdominguez-chwy/omarchy-popburst-theme
```

```bash
omarchy theme set popburst
omarchy theme bg next
```

Update later:

```bash
omarchy theme update
```

## Full extras (rainbow borders + tuned Neovim)

Git-installed themes regenerate Lua/terminal configs from `colors.toml`. To keep the hand-tuned extras:

```bash
rm -rf ~/.config/omarchy/themes/popburst/.git
omarchy theme set popburst
```
